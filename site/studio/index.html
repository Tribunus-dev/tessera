Product · v1

Tessera Studio. Local AI for your Mac.

A native Mac and iOS app that runs Tessera-quantized models on your device. Text, vision, audio, and speech. The data never leaves. The agent loop keeps you in control. The flywheel runs while you don't.

The product surface

Three destinations. Eight tools. One app.

Tessera Studio is a single window with three destinations and a registry of eight tools that the agent loop can call. The destinations are not menus; they are different working modes for different things you might be doing with the model.

Library

The model browser. Browse Tessera-trained models and vanilla GGUFs side by side. Inspect the signed receipt on any artifact. Load a model into the Playground or a Run.

Playground

The chat surface. Single-turn and multi-turn. Streaming, cancellation, observable. The agent loop runs here when the model decides to call a tool, and the ANE prefill kicks in for long prompts.

Runs

The instrumented surface. Every model call is logged with timing, dispatch (CPU / GPU / ANE), token counts, and a snapshot of the per-tensor activation that ran. Calibrate, evolve, quantize, and evaluate from here.

The eight tools

What the agent can do.

The agent loop in Tessera Studio can call any tool in the registry. Each tool is a typed component with a JSON Schema, a streaming or one-shot contract, and an approval level. The default approval level is notify: the agent runs the tool, you see a system message about what it did.

The agent loop

A full agent app, not a chatbot.

Tessera Studio is built on a real agent loop with cancellation, observable state, and an approval engine. The approval engine has four levels:

  • auto — the tool runs without any surface signal (read-only tools like inspect_sidecar)
  • notify — the tool runs, you see a system message about what it did (default for most tools)
  • prompt — you get a confirmation dialog before the tool runs (default for quantize, convert, evolve)
  • denied — the tool cannot run from the loop (e.g. rm -rf shell escape, never wired)

The chat journal is SwiftData; every run, every tool call, every approval decision is recorded. The journal is local. It does not sync to anything.

Apple Intelligence annotations

AION. On-device annotations, Mac only in v1.

AION (Apple Intelligence On-device Notes) is the v1 mediator between the agent and the model. It runs Apple Intelligence on the same Mac the model runs on, and uses the on-device model to annotate long outputs with sections, code blocks, and key terms. AION is Mac-only in v1; the iOS build will pick it up in v2 when Apple ships the same surface to iPhone.

AION never sees data that the model hasn't already seen. The annotation happens on the model's output, in the same process.

The flywheel

While you're not using it.

Tessera Studio is opt-in for the flywheel. When you opt in, the app runs a small training job during idle time (laptop plugged in, on Wi-Fi, screen off, app backgrounded) on a sanitized baseline derived from your recent usage. The sanitized baseline is the result of the Tessera data pipeline; the raw inputs never leave the device. The trained delta is shipped to the Calibration Commons with your consent. The next Tessera release carries your delta's contribution. Full details on how the flywheel works.
