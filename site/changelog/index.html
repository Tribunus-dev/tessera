Not yet

  • Auto-build calibration corpus from the user's own usage (privacy-preserving; CC BY 4.0 license, scrubber-first).
  • Self-improving drafter training (Qwen-class trunk + DFlash + DSpark, regime-routed; the MVP is the multi-dimensional behavioral eval + capability archive).
  • Hardware-backend reach beyond Apple Silicon (Tessera is macOS / iOS first; the pipeline is backend-agnostic but the runtime is Apple-targeted today).

Releases, in order.

2026-08-05 · Site regeneration (Phase 1)

The docs site regenerates against the privacy + flywheel framing. New pages: /studio/, /how-it-works/, /how-tessera-differs/, /concepts/. The architecture page gains the memory wall and the dispatch policy sections. The status table moves to the top of the changelog (no more separate /status/ route). Tier 1 concept cards ship with concise analogies. Inline glossing on L0 / L1 pages. The three-tier property regime is surfaced on the home page with the runnability table. The comparison page is the second-most-important entry point after the home page.

2026-08-05 · Site bootstrap

The tessera.tribunus.dev docs site is bootstrapped on the feat/docs-bootstrap branch. Hand-authored HTML, Observatory design language, GitHub Pages deploy on push to main. Six routes initially: home, start, architecture, evidence, status, changelog, colophon.

Backfill · The pipeline as it stands today

The receipts for the recent waves are in the evidence page. Each entry below is the user-visible change the wave produced; the receipt carries the per-tensor t_l² and the kernel's hash.

WaveUser-visible changeReceipt
Tessera Studio Phase 1 + 2 The macOS / iOS app gains a workflow data model and a SwiftUI graph editor for wrapping the calibration tools as composable nodes. Repository
Clip-capture v2 Multimodal activation capture against the actual C++ mtmd clip graph; AudioToolbox decode for WAV / MP3 / FLAC / AAC / ALAC; dead-node detection at the graph level. Evidence
Runtime-aware kernel-dequant fitness The calibrator's fitness signal is now the kernel's dequant output, not an offline proxy. The L1 path is the default; the legacy offline measurement stays as an opt-in env var. Evidence
Regime router Per family + shape, dynamic dispatch to the v2 quant functions replaces the static thresholds. Evidence
Self-improving drafter training (MVP) The training driver for the LK / autoregressive drafter path is native C++; the data path traces → dense reconstruction → graph loss → API selection works end to end. Evidence
Singular-GGUF commitment Multimodal absorption is now mechanical end to end: writer absorbs vision / audio / mm projector as first-class components of the singular GGUF. The multimodal pipeline does not split the artifact across files. Evidence
