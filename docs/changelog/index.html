Changelog

What shipped, in order.

Each entry is one release, named for the user-visible change, with the receipts that produced it linked from the evidence page.

Bootstrap

The site goes live.

The tessera.tribunus.dev docs site is bootstrapped on the feat/docs-bootstrap branch. Hand-authored HTML, Observatory design language, GitHub Pages deploy on push to main. The first public changelog is a backfill of the receipts that produced the pipeline as it stands today.

The pipeline as it stands today.

What changed since bootstrap.

The waves below landed on main after the bootstrap backfill. The L1–L6 spine is the headline: the measurement loop from the v3.1 spec is now implemented in C++, and the fitness chain runs from the row-capture triggers through the Hessian scorer to the tail-weighted quant loss.

WaveUser-visible changeStateReceipt
L1–L6 telemetry spine (v3.1 spec) The six-layer runtime-aware measurement loop lands in C++: trigger-gated row capture with a true FP16 reference (L1/L1.5), activation-space differential with spectral norm + effective rank (L2), KL divergence with four-forward attribution (L3), domain-weighted prompt bank with per-layer flag telemetry (L4), Hessian sensitivity scorer with Cholesky + Phase D dispatch (L5), tail-weighted quant loss with acceptance verdict (L6). The FP environment block rides in the v3 sidecar. Released Repository · Evidence
Granite T640 family support granite-4.1-30b, guardian-4.1-8b, and granite-4.0-h-small are first-class T640 targets; granite4vision (text / vision / video), granite-docling (SigLIP + Idefics3 QFormer), granite-speech-plus (audio feature concat), and the modern-bert embeddings convert and load through the singular GGUF pipeline. Released Repository
Nemotron 3.5 conversion Full BF16 conversion with per-expert FFN paths and MTP blocks. Readback-validated: 6,343 tensors on disk, shapes and dtypes checked against the source model — not just the file size. Released Repository
D-PACE loss + DFlash block dataset Adaptive per-position D-PACE weights (the product of the per-step acceptance probabilities) replace the fixed exponential decay; --tessera-dpace selects the loss. The DFlash block dataset — target tokens, acceptance probabilities, baked smoothed + normalized weights — emits from spec_calib.v2. The drafter training driver is next: the DFlash drafter is feature-conditioned, so the block dataset is necessary but not sufficient — the offline feature-capture pipeline is the missing link. Qualifying Evidence · Repository
Studio HIG pass, Phases 11–13 Streaming pipeline, ghost text, and the diff overlay land (Phase 11); Sheets, Docs, Notes, and Code surfaces split into host/child detail + editor views (Phase 12); the Phase 13 review files 60+ must-fix findings and the Tier 1–3 fix waves land in the same batch. Released Repository
Studio agent-loop hardening (ux-fatigue waves 1A–3D) Approval tiers with a tiered approval sheet, a notification budget actor with onFinished hooks, time-limited undo, audit-log HEAD chip + side panel, chat dock progress feed, ReceiptsCoordinator on AsyncStream, citation chips with inline hard-stop, and a research brief grounding the fatigue model.
